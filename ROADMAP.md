# BianLunTing Roadmap

This roadmap describes the intended open-source direction of BianLunTing. It is not a deployment commitment.

## Available Today

- declarative policy packs;
- pluggable data-source packs and collector registry;
- MySQL Text-to-SQL evidence retrieval;
- structured table-payload ingestion;
- execution-feedback SQL diagnosis and repair;
- structured evidence cards;
- evidence-constrained multi-agent deliberation;
- conflict detection, arbitration, trace, memory, and human-review primitives;
- Vue interface and FastAPI service.

## Near Term

- add an English policy-pack authoring tutorial;
- publish minimal replayable demo fixtures;
- improve cross-platform startup and test scripts;
- expand contributor documentation and issue templates;
- add clear evaluation commands for SQL and multi-agent ablations.

## Medium Term

- add Excel and HTTP API collectors;
- add policy-pack schema validation and version migration guidance;
- expand trace replay and audit exports;
- document privacy threat models and deployment boundaries;
- add more public or simulated local-governance examples.

## Long Term

- evaluate adapters for authorized external business systems;
- add region-aware policy-pack composition;
- support benchmark-style governance reasoning tasks;
- improve human-review workflows for ambiguous or conflicting evidence.

## Out of Scope

BianLunTing is not intended to make binding public-service decisions without authorized human review.
